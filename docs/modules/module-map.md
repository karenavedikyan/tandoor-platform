# Карта модулей

## Платформенное ядро

Назначение: общая основа экосистемы.

Состав:

1. Авторизация.
2. Пользователи.
3. Организации.
4. Роли и права.
5. Справочники.
6. Документы.
7. Уведомления.
8. События.
9. Журнал действий.
10. API.

## Кабинет дилера

Назначение: основной внешний интерфейс для партнеров.

MVP:

1. Вход дилера.
2. Каталог.
3. Персональные условия.
4. Заказ.
5. Повторный заказ.
6. Статусы.
7. Документы.
8. Рекламации.
9. Акции и материалы.

## Кабинет продаж / CRM

Назначение: рабочее место менеджера Tandoor.

MVP:

1. Карточка дилера.
2. Заказы дилера.
3. Задачи.
4. История взаимодействий.
5. Коммерческие условия.
6. Базовая аналитика.

## Товар, склады и логистика

Назначение: прозрачность доступности, резервов и отгрузок.

MVP:

1. Товары и SKU.
2. Остатки.
3. Доступность.
4. Резерв.
5. Комплектация.
6. Статус отгрузки.

## Сервис и рекламации

Назначение: обработка претензий и обратная связь в качество.

MVP:

1. Рекламация из заказа.
2. Вложения.
3. Причины.
4. Статусы.
5. Ответственный.
6. Решение.
7. SLA.

## Маркетинг и обучение

Назначение: продвижение продукции Tandoor через дилеров.

MVP:

1. Акции.
2. Маркетинговые материалы.
3. Обучающие материалы.
4. Уведомления.
5. Базовая аналитика использования.

## Аналитика

Назначение: управленческая прозрачность.

MVP:

1. Заказы по статусам.
2. Продажи по дилерам.
3. Активность дилеров.
4. Рекламации по статусам.
5. Просрочки обработки.

## Кабинет поставщика

Назначение: прозрачное взаимодействие по закупкам и снабжению.

Рекомендуемый горизонт: после стабилизации дилерского, продажного, складского и сервисного контуров.
