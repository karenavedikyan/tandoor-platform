# Единый визуальный стиль навигации (sidebar / mobile drawer)

## Назначение

Во всех личных кабинетах платформы (директор, РОП, менеджер, маркетолог, аналитик и др.) используется **один и тот же язык оформления** пунктов меню, групп и нижнего блока настроек. **Маршруты, доступы и бизнес-структура** меню задаются в `getPilotNavigation` (`auth-access.ts`) и **не меняются** этим документом.

## Палитра Tandoor

| Токен        | HEX       | Применение                          |
|-------------|-----------|-------------------------------------|
| primary     | `#9ACA3C` | активная полоса слева у пункта      |
| primary hover | `#86B832` | hover кнопок (где уместно)       |
| text        | `#222631` | активный текст пункта               |
| muted       | `#8F96B0` | неактивный текст, подписи групп    |
| surface     | `#FFFFFF` | фон карточек / sheet                |
| light surface | `#EEEFF6` | фон активного пункта, hover       |
| border      | `#E3E6F3` | границы, бейджи                    |

## Строка навигации (`navRowClass`)

- Высота строки **~44px** (`min-h-[44px]`, `max-h-12`), горизонтальные отступы **одинаковые** (`px-3`), скругление **`rounded-lg`**.
- Текст **в одну строку** с `truncate` для длинных подписей.
- **Active:** светлый фон `#EEEFF6` + **вертикальная полоса 3px** слева `#9ACA3C`, шрифт semibold, цвет текста `#222631`.
- **Inactive:** приглушённый текст `#8F96B0`, полоса слева прозрачная.
- **Hover:** лёгкий фон `#EEEFF6` (прозрачность ~90%).

Одинаковый стиль применяется к:

- плоскому меню (`layout: "flat"`) — менеджер, маркетолог, аналитик;
- пунктам внутри групп и к **отдельным** пунктам между группами (например «План-факт и KPI» у директора/РОПа).

## Группы (`navGroupHeaderClass`)

- Заголовок группы: **uppercase**, компактная строка, **chevron** справа для раскрытия.
- Свернутая группа **не** получает «карточного» белого фона и не выглядит как активный раздел — только лёгкий hover.
- Под заголовками групп **нет** дублирующих текстовых сводок со счётчиками: числа показываются только в бейджах пунктов (клиенты / ТТ) и в других элементах UI по необходимости.
- Для **«В разработке»** пункты ведут на **реальные маршруты**, справа — компактный muted-бейдж «в разработке» (`navWipBadgeClass`), без имитации `disabled`.

## Нижний блок (`SidebarNavFooter`)

- Имя пользователя + опциональная **роль** (`userSubtitle` из `App.tsx`).
- Секция **«Настройки»** с `button-nav-settings-toggle`: по умолчанию **свернута** в mobile drawer; внутри — выбор темы и выход.
- Компактная строка текущей темы: `nav-theme-current`; кнопки темы: `button-nav-theme-light` / `dark` / `system`; выход: `button-nav-logout`.
- Контейнер: `nav-settings-section`; раскрытые опции темы также помечены `menu-theme-options` и `text-current-theme` для совместимости с прежними сценариями.

Desktop topbar по-прежнему использует `ThemeToggleDesktop` (dropdown); в узком sidebar тема дублируется в компактном футере.

## Группированное vs плоское меню

| Модель (`PilotNavigationModel`) | Роли (пример)     | Поведение |
|----------------------------------|-------------------|-----------|
| `grouped` + `standaloneItems`    | Директор, РОП     | Группы «Клиентская база» / «В разработке» + отдельная строка «План-факт и KPI» между первой группой и второй (порядок см. `director-rop-navigation.md`). |
| `flat`                           | Менеджер, маркетолог, аналитик | Только список строк того же визуального типа. |
