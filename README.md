# Tandoor Platform

Стартовый репозиторий для реализации цифровой экосистемы Tandoor.

Проект развивается как единая B2B2C-платформа с общим ядром данных, модульной архитектурой и ролевыми интерфейсами для сотрудников Tandoor, дилеров, поставщиков и будущих B2C-сценариев через дилерскую сеть. Платформа рассчитана на сквозные роли (клиенты и дилеры, менеджеры, регионалы, руководители, другие отделы) и интеграции с **1С**, **Bitrix**, **Bitrix24**, **Excel и Google-источниками**, а также на связь с текущим **Bitrix-сайтом**.

## Цель

Создать платформу, которая:

1. Сохраняет текущий сайт, каталог и клиентский контур.
2. Добавляет закрытый продуктовый слой для дилеров и внутренних команд.
3. Позволяет развивать каждый модуль отдельно.
4. Интегрирует модули через общие сущности, API, события и единую модель статусов.
5. Снижает ручные операции между продажами, складом, логистикой, сервисом и маркетингом.

## Приложение

Базовый каркас расположен в `apps/platform`.

Технологический стек стартового шаблона:

1. React.
2. Vite.
3. Express.
4. Tailwind CSS.
5. shadcn/ui.
6. Drizzle ORM.
7. SQLite для локального persistence-слоя.

## Быстрый старт

```bash
cd apps/platform
npm install
npm run dev
```

## Первый фокус реализации

Первый MVP должен быть построен вокруг дилерского заказа:

1. Единая авторизация и роли.
2. Кабинет дилера.
3. Каталог и доступность товара.
4. Создание и повторение заказа.
5. Статусы исполнения.
6. Документы.
7. Кабинет менеджера продаж.
8. Передача заказа в складской и логистический контур.
9. Рекламация из заказа.
10. Базовая аналитика.

## Принцип разработки

Каждый модуль реализуется как отдельный блок с собственным паспортом, но подключается к общему ядру:

1. Общие сущности.
2. Единые роли и права.
3. API-контракты.
4. События.
5. Единая модель статусов.
6. Журнал действий.
